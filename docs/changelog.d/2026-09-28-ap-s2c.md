### AP-S2c – Plugin ohne Windows bauen: NuGet statt Referenz-Assemblies (2026-09-28)

Anforderungen: TK 10.1, 10.5, 18 · NFA (Wartbarkeit) · ADR-S2c

- **Befund:** `NINA.Plugin` 3.2.0.9001 bringt alle fünf Adapter-Assemblies (`NINA.Sequencer`, `NINA.Equipment`, `NINA.WPF.Base`, `NINA.PlateSolving`, `NINA.Image`) als eigene NuGet-Pakete mit. Die in TK 10.5 geplante Kopie aus der NINA-Installation (`refs/`, `tools/fetch-nina-refs.ps1`, CI-Auftrag `refs`) entfällt. Das Rig läuft mit NINA 3.2.
- **Nachweis auf macOS (arm64, .NET SDK 8.0.425)** mit den Projekten unter `spikes/nina-build/`: (a) Kern mit Tests, (b) Adapter mit `UseWPF` ohne XAML (Erbe von `SequenceItem`, Mediatoren aus `NINA.Equipment` und `NINA.WPF.Base`, `PluginBase`), (c) derselbe Adapter ohne `UseWPF`, (d) Ansichten mit XAML. Alle vier bauen ohne Windows und ohne `-p:`-Schalter; damit ist auch `NinaPm.Nina.Ui` lokal baubar.
- **Build-Dateien:** `apps/nina-plugin/Directory.Build.props` (`NinaVersion` 3.2.0.9001, `EnableWindowsTargeting`) und `Directory.Build.targets` (`PlatformTarget` x64, `NoWarn` NU1701). Die Bedingung auf `TargetFramework` greift in der Props-Datei nicht, dort ist das Ziel-Framework noch leer; das TK-Snippet hätte `PlatformTarget` nie gesetzt. `NINA.Plugin` wird mit `IncludeAssets="compile"` eingebunden: Mit `ExcludeAssets="runtime"` landete WebView2 in der Ausgabe.
- **`tools/nina-build-check.sh`:** prüft, dass alle `NINA.*`-Pakete in `NinaVersion` aufgelöst sind, dass die Ausgabe nur eigene DLLs enthält und dass keine DLL im Git liegt. Gegenproben mit falscher Version, mit `ExcludeAssets="runtime"` und mit versionierter DLL schlagen jeweils an.
- **CI `plugin.yml`:** `cross-build` (ubuntu-latest, Nachweisprojekte bauen und testen, Prüfskript) und `build` (windows-latest, derselbe Build). AP-16a zieht beides auf die echte Lösung.
- **Doku:** TK 10.1/10.5/18 als Spec-Ergänzung, `docs/concept/INDEX.md` neu erzeugt, `CLAUDE.md` (Umgebung, Befehle, Regel 13), `START.md`, `execution.md`, H-14 (ohne DLL-Kopie, Versionsabgleich je NINA-Version), AP-S2c- und AP-16a-Brief, `THIRD_PARTY_NOTICES.md` (NINA, MPL-2.0, nur kompiliert).
- **Status:** AP-35 ☑ 28.09.2026 (Abnahme Sven), AP-S2c ◐.
