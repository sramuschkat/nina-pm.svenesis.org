### NINA-Plugin 0.4.16: richtige Dauer eines Flips durch NINAs Trigger (2026-10-07)

Anforderungen: FA-NIN-24, FA-SIM-10; Rig-Log Starfront 06./07.10.2026

- Flippt NINAs Meridian-Flip-Trigger vor einer Belichtung, erkennt das Plugin den Flip erst danach. Bisher zählte es dabei die Belichtung zur Flipdauer mit. In der Rig-Nacht wurden so 1903 s gemeldet; der Flip selbst dauerte etwa 21½ min (Warten auf den Meridian, Slew, Autofokus, Guiding), dazu kamen 600 s Belichtung. Jetzt meldet das Plugin nur noch die Flipzeit. Die Lücke „Meridian-Flip“ im Ist und die Kennzahlen der Session stimmen damit.
