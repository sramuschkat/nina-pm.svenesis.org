# Menschliche Aufgaben (Sven)

Aufgaben, die Claude Code **nicht** selbst erledigen kann oder darf. Zwei Spalten:
- **Voraussetzung für** = Arbeitspaket, das ohne diese Aufgabe **nicht beginnen** kann (echte Startsperre; Claude Code fragt nach statt zu umgehen).
- **Abnahme von** = Arbeitspaket, das ohne diese Aufgabe **nicht abgenommen** werden kann; die Arbeit und der PR laufen trotzdem (Status bleibt ◐).

Mehrstufige Aufgaben (H-04, H-06, H-22) sind so zu lesen: Claude Code liefert Code und Skripte, Sven führt den Schritt lokal mit seinem Admin-Profil aus und gibt Ausgabe bzw. Protokoll zurück, danach folgt die Abnahme. Deploy und AWS-Zugriffe laufen ausschließlich lokal bei Sven; GitHub hat keinen AWS-Zugang (SV-13, E1, 21.09.2026). Status hier pflegen (☐ offen · ☑ erledigt, Datum).

## Regeln für Claude Code
- Nie Geheimnisse erfragen oder in Dateien/Chat schreiben; nur Namen der SSM-Parameter verwenden.
- Nie `cdk bootstrap`, `cdk deploy`, `pnpm deploy:prod` oder `pnpm test:dsql` ausführen und keine AWS-Ressourcen anlegen; das macht Sven lokal (H-04, H-06, H-22). Claude Code schreibt die Skripte und wertet Ausgabe bzw. Protokoll aus.
- Nie Tags setzen oder Releases veröffentlichen; Versionsnummer und CHANGELOG im PR vorbereiten.
- Nie Website-Repository, Website-CloudFront-Distribution oder DNS-Einträge außer `nina-pm.svenesis.org` ändern.
